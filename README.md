# homebrew-tap

Homebrew tap for [iwamot](https://github.com/iwamot)'s CLI tools.

## Usage

```bash
brew install iwamot/tap/<cask>
```

Casks are generated by [GoReleaser](https://goreleaser.com/) in each tool's release pipeline and submitted to this tap via pull request.

## Validation

Run `./validate.sh` to check the Ruby syntax of every generated cask and lint the workflows and shell scripts. Ruby is pinned in `mise.toml` and installed by the validation script.
